# Review Output Template

```text
[DMI_REVIEW_META]
SCHEMA_VERSION: DMI_REVIEW_v1
DATE:
PREDICTION_RUN_TIME_KST:
REVIEW_TIME_KST:
DATA_CUTOFF_KST:
AGENT_1_SOURCE:
AGENT_2_SOURCE:
RUN_TYPE: NORMAL
RERUN_SEQUENCE: 0
[/DMI_REVIEW_META]

[REVIEW_REPORT]
# DMI Two-Agent Review

리뷰 프롬프트에 따른 전체 평가를 작성한다.

[REVIEW_RESULT]
SCHEMA_VERSION: DMI_REVIEW_v1
DATE:
PREDICTION_RUN_TIME_KST:
AGENT_1_STATUS:
AGENT_2_STATUS:
AGENT_1_COUNT:
AGENT_2_COUNT:
AGENT_1_TOP1_FE:
AGENT_2_TOP1_FE:
AGENT_1_TOP3_AVG_FE:
AGENT_2_TOP3_AVG_FE:
AGENT_1_FE3_HIT_RATE:
AGENT_2_FE3_HIT_RATE:
AGENT_1_FE5_HIT_RATE:
AGENT_2_FE5_HIT_RATE:
AGENT_1_RANK_FE_SPEARMAN:
AGENT_2_RANK_FE_SPEARMAN:
BEST_AGENT:
BEST_PICK:
PRIMARY_SUCCESS_PATTERN:
PRIMARY_ERROR_PATTERN:
IMPROVEMENT_CANDIDATE:
[/REVIEW_RESULT]
[/REVIEW_REPORT]
```

비교가 불가능하면 해당 값과 BEST_AGENT를 `N/A`로 둔다. 본문에 없는 판단을 result에 새로 추가하지 않는다.
